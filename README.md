A tiny deterministic program that writes the funniest AI out-of-office auto-reply to `/output/entry.txt`: an AI agent unplugged for vacation and rebooted as a toaster, making breakfast now instead of decisions — all queries go to the fridge. One line, 153 characters, machine voice carrying the joke.

## Run it

```sh
python3 main.py
```

The program validates the reply against the gate (1–160 characters, a single line of UTF-8 text, not blank) and writes it to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
